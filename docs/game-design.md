## 練習庫（待實作入口）

首頁第三卡改為「練習場」或類似名稱，作為小遊戲庫入口，收納顆粒度較小的刷題模式。

| 小遊戲 | 狀態 | 說明 |
|---|---|---|
| 拆彈 | 現有，需降級 | 計時多選一 + 5 條命，arcade 感 |
| 知識點還原 | 待開發 | 題幹關鍵字塗黑，從詞庫填字，語意解謎風 |
| 翻牌連線 | 待開發 | 配對知識點，類多鄰國翻牌 |
| 排序拖曳 | 待開發 | 步驟/事件打散後拖曳還原，適用：實驗步驟、數學證明、尺規作圖、數學計算、歷史時間軸、地理方位 |

---

## 線索卡收集冊（跨模式系統，待開發）

學生遊玩各模式時累積「線索卡」，卡片內容來自題目的關鍵知識點，收集冊可直接當複習工具使用。

- 設計新模式或題目資料結構時，考慮哪些欄位可作為線索卡內容輸出
- 與 RAG 問答長期願景共用同一份知識資料

---

## 長期願景：RAG 問答

當題目量累積到一定程度，以答案、引導作答、偵探筆記卡的資料做 RAG，讓學生可以自由問答。有 API 成本，屬於長期規劃。
